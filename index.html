자주 쓰는 문구

문구를 추가하면 누르는 즉시 PC로 타이핑합니다. 이 폰에만 저장됩니다.

최근 보낸 텍스트

누르는 즉시 PC로 입력됩니다. Ctrl·Shift·Alt·Win은 한 번 누르면 다음 키 하나에만, 두 번 누르면 다시 누를 때까지 적용됩니다.

USB(OTG) 포트 용도

바꾸면 기기가 저장 후 재부팅하고, 앱이 자동으로 다시 연결합니다.

PC에 이 시간 동안 키 입력이 없으면 기기가 선택한 키를 누릅니다. F13~F24는 거의 모든 프로그램이 무시하는 키이고, 일부 보안 프로그램이 F키를 입력으로 치지 않으면 Shift를 고르세요. 화면보호기 대기 시간보다 짧게 정하세요. 설정은 기기에 저장되어 폰 앱을 닫아도, 기기를 껐다 켜도 계속 동작합니다.

기기가 알고 있는 PC 입력 모드: -

PC 실제 모드와 다르면(한글이 영문으로 쳐지는 등) 아래 버튼을 누르세요. 키는 입력되지 않고 기기의 기억만 바뀝니다.

이 ClipKey의 별명

ClipKey에 저장되어 앱 상단과 PC·태블릿의 블루투스 목록에 "별명 (ClipKey-XXXX)"으로 표시됩니다. (최대 한글 약 10자)

PC 블루투스 연결

PC는 여기서 허용할 때만 페어링할 수 있습니다(60초, 1대). PC와 이 화면에 같은 숫자가 나오는지 확인한 뒤 승인합니다. 유선(USB)으로 쓸 때는 필요 없습니다.

페어링된 PC·태블릿

처음 연결할 때 Windows / iPad·Mac을 자동으로 구분해 한/영 전환 방법과 입력 속도를 맞춥니다. 틀리면 여기서 바꾸세요. (최대 6대 기억, 동시 연결 2대)

펌웨어-
설정 코드 변경

설정 코드가 있으면 다른 폰을 BOOT 버튼 없이 등록할 수 있습니다. 0000처럼 쉬운 코드는 피하세요.

폰 등록에는 기기의 설정 코드가 필요합니다. 코드 없이 등록하려면 기기의 BOOT 버튼을 짧게 누른 뒤 60초 안에 등록하세요. 기기를 초기화하려면 BOOT 버튼을 5초 누르세요(등록된 폰·PC 모두 삭제).

      (보드 뒷면 USB-OTG / IN-OUT 패드 연결 또는 전원 공급형 OTG 허브).
