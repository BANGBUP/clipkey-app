기기 미연결 PC Caps USB

위 한글/영문 표시가 PC·태블릿의 실제 입력 상태와 다르면 눌러서 맞추세요 (키는 입력되지 않음).

여기에 입력하는 내용이 그대로 PC에 타이핑됩니다. PC의 커서는 입력한 위치 끝에 있다고 가정합니다.

USB(OTG) 포트 용도

바꾸면 기기가 저장 후 재부팅하고, 앱이 자동으로 다시 연결합니다.

PC에 이 시간 동안 키 입력이 없으면 기기가 선택한 키를 누릅니다. F13~F24는 거의 모든 프로그램이 무시하는 키이고, 일부 보안 프로그램이 F키를 입력으로 치지 않으면 Shift를 고르세요. 화면보호기 대기 시간보다 짧게 정하세요. 설정은 기기에 저장되어 폰 앱을 닫아도, 기기를 껐다 켜도 계속 동작합니다.

이 ClipKey의 별명

ClipKey에 저장되어 앱 상단과 PC·태블릿의 블루투스 목록에 "별명 (ClipKey-XXXX)"으로 표시됩니다. (최대 한글 약 10자)

PC는 여기서 허용할 때만 페어링할 수 있습니다(60초, 1대). PC와 이 화면에 같은 숫자가 나오는지 확인한 뒤 승인합니다. 유선(USB)으로 쓸 때는 필요 없습니다.

페어링된 PC·태블릿

처음 연결할 때 Windows / iPad·Mac을 자동으로 구분해 한/영 전환 방법과 입력 속도를 맞춥니다. 틀리면 여기서 바꾸세요. (최대 6대 기억, 동시 연결 2대)

폰 등록에는 기기의 설정 코드가 필요합니다. 기기를 초기화하려면 BOOT 버튼을 5초 누르세요(등록된 폰·PC 모두 삭제).

PC 블루투스 연결

⚠ 역전류 주의

호스트 모드에서는 보드가 OTG 포트로 5V를 내보내야 키보드가 동작합니다 (보드 뒷면 USB-OTG / IN-OUT 패드 연결 또는 전원 공급형 OTG 허브).

이 상태에서 OTG 포트를 PC에 꽂으면 보드의 5V와 PC의 5V가 직접 맞물려 PC USB 포트나 보드가 손상될 수 있습니다.

  • 호스트 모드에서는 OTG 포트에 키보드만 꽂으세요.
  • 전원은 메인(UART) 포트로 넣으세요.
  • 다시 PC에 직접 꽂으려면 먼저 "PC 연결" 모드로 되돌리고 패드 연결을 해제하세요.
