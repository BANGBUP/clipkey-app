ClipKey 처음 설치

새 보드에 펌웨어 넣기

  1. PC의 크롬 또는 엣지에서 이 페이지를 엽니다(휴대폰·아이폰은 안 됨).
  2. 보드를 USB 케이블로 PC에 꽂습니다. ESP32-S3 보드는 UART(또는 COM)라고 적힌 단자에 꽂으세요.
  3. 아래 설치를 누르고, 목록에서 보드의 포트(USB 직렬 장치, COM…)를 고릅니다.
  4. "Erase device"(기기 지우기)는 새 보드면 체크하세요. 이미 쓰던 ClipKey를 다시 설치할 때 체크하면 폰·PC 등록이 지워집니다.
  5. 1분 정도 기다리면 끝납니다. 보드가 다시 켜지고 블루투스 이름 ClipKey-XXXX로 보입니다.
이 브라우저는 USB 직렬 연결을 지원하지 않습니다. PC의 크롬 또는 엣지로 여세요. 보안 연결(https)에서만 설치할 수 있습니다.

설치한 다음

  1. 보드의 BOOT 버튼을 짧게 누른 뒤, 폰 앱에서 연결해 등록합니다.
  2. 별명을 정하면 이름이 ClipKey-별명으로 바뀌어 여러 대를 구분하기 쉽습니다.
  3. 이후 새 펌웨어는 폰 앱의 설정 → 펌웨어 → 최신 버전으로 업데이트로 받습니다.

연결이 안 될 때

  • 포트 목록에 보드가 없으면 데이터 전송이 되는 USB 케이블인지 확인하고, 다른 단자에 꽂아 보세요.
  • 연결에 실패하면 보드의 BOOT 버튼을 누른 채 RESET(EN)을 한 번 눌렀다 떼고, 다시 설치를 누르세요.
  • Windows에서 포트가 안 보이면 보드의 USB 칩 드라이버(CH340/CH343, CP210x)를 설치하세요.
