관리자 암호

암호가 맞지 않습니다.

새 보드에 처음 설치

  1. PC의 크롬 또는 엣지에서 엽니다(휴대폰은 안 됨).
  2. 보드를 USB로 꽂습니다. ESP32-S3 보드는 UART(COM) 단자에 꽂으세요.
  3. 설치를 누르고 보드의 포트(COM…)를 고릅니다.
  4. Erase device(기기 지우기): 새 보드나 완전 초기화면 체크. 체크하지 않으면 펌웨어만 다시 깔리고 폰·PC 등록과 설정은 남습니다.
  5. 1분 정도면 끝나고, 보드가 블루투스 이름 ClipKey-XXXX로 켜집니다.
이 브라우저는 USB 직렬 연결을 지원하지 않습니다. PC의 크롬 또는 엣지로 여세요. 보안 연결(https)에서만 설치할 수 있습니다.

설치한 다음

  1. 보드의 BOOT 버튼을 짧게 누른 뒤, 폰 앱에서 연결해 등록합니다.
  2. 별명을 정하면 이름이 ClipKey-별명으로 바뀝니다.
  3. 이후 새 펌웨어는 폰 앱의 설정 → 펌웨어 → 최신 버전으로 업데이트로 받습니다.

연결이 안 될 때

  • 포트 목록에 보드가 없으면 데이터 전송이 되는 케이블인지 확인하고 다른 단자에 꽂아 보세요.
  • 연결에 실패하면 보드의 BOOT를 누른 채 RESET(EN)을 한 번 눌렀다 떼고 다시 설치를 누르세요.
  • Windows에서 포트가 안 보이면 USB 칩 드라이버(CH340/CH343, CP210x)를 설치하세요.
